Shows the Going, Waitlist and Not Going lists for an upcoming event. Anyone can use it, and the reply is visible to the channel.

```
/rsvps event:thursday
```

- **event** matches part of the title; the first upcoming match is used.
- Guests show as `Name (+1)` and are included in the Going count, the same as in RSVP posts.
- Lists come from what the bot has stored. They're kept current for the next event within 24 hours; events further out may not have RSVPs fetched yet.
